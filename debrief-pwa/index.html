Import from a link

Paste a direct link to an .igc file — from a club site, a competition results page, or a league's own download button. Works with no key and no account. If the flight needs a login, download it in your browser and drop the file in.

…or paste the file contents

Needs nothing at all — no key, no server, not even a connection. If a friend sends you an IGC in a message or email, open it, copy the text and paste it here.

Competition task

Enter the task code your organiser published (4 letters, or the longer permanent hash). The cylinders appear on the map and every loaded pilot is checked against them. From XContest's open task store — no key, no account.

One-tap import from XContest

A bookmark you add once. Open any flight page on XContest — or DHV-XC, a comp site, anywhere with an IGC download — and tap it. The flight opens here, already loaded. It runs in your browser using your own login, so it works on flights only you can see.

✈ Send to Debrief
How to add it

Mac / PC: drag the blue button up to your bookmarks bar.

iPad / iPhone: tap Copy above. In Safari, bookmark any page (Share → Add Bookmark), then open Bookmarks → Edit, rename it “Send to Debrief” and replace its address with what you copied.

Nothing is uploaded anywhere — the flight goes straight from the page you're looking at into this app.

Import from XContest

Pick a date and country, then choose the pilots to load. Needs your own XContest API key — stored on this device only, never sent anywhere but XContest.

API key

XContest publishes no open API — their robots.txt disallows the flight-search and track-download paths, so this uses their partner API, which needs a key you request from them.
