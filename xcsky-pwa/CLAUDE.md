# Sky Monkeys — app notes

"Sky Monkeys": free soaring/XC weather, map-first (SkySight-style).

Main screen is a full-map gridded forecast overlay (batched multi-point Open-Meteo → climb/top/base/wind layers, 7-day time scrub), plus KK7 thermal/skyways overlays, live pilots via OGN, and a tap-anywhere point forecast (time-height plot) in a bottom sheet.

Entirely keyless: Open-Meteo weather, Leaflet + Esri/OpenTopoMap tiles, thermal.kk7.ch overlays, live.glidernet.org pilots. No worker, no key, no build step.
