Thermal pack builder

Builds the instrument's area pack: where thermals have historically been (KK7), how likely by season and time of day, and how good the chosen day looks (Open-Meteo). Copy the file to the instrument before flying; it can't reach the internet in the air.

The day, hour by hour

Day factor scales every hotspot's historical chance: 1.0 is a typical thermal day, above is better, 0 means don't expect thermals. It comes from boundary-layer depth, sunshine, low cloud and rain.

Getting it onto the instrument

Put hotspots.pghs in paraglider-instrument/data/ and upload the file system: pio run -e xiao_esp32s3 -t uploadfs. The instrument loads it at boot (console: pack shows what it loaded). In the simulator, use “Thermal pack” to try it.

Status: the KK7 reader is written from KK7's published layer names and hasn't been checked against a live download yet. If the log says “0 hotspots”, the format differs: send the log.
