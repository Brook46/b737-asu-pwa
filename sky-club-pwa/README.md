# Sky Club

A tap-and-look solar system and real-sky explorer, built for a very young kid (no reading required).

- **Explore** — an animated solar system. Tap any planet (or the Sun, or the Moon) for a spinning close-up, its name, and one fact — all read aloud.
- **Sky** — point your phone at the sky (or drag if you're indoors) to find the real Sun, Moon, planets and a handful of bright stars and constellations, wherever they actually are right now. Bodies just out of view get a little arrow pointing you toward them.

Entirely offline-capable after first load: no accounts, no API keys, no server. Real-time positions come from the vendored [astronomy-engine](https://github.com/cosinekitty/astronomy) library; planet textures are the free CC-BY set from [solarsystemscope.com](https://www.solarsystemscope.com/textures/).

See `CLAUDE.md` for how the two screens are built.
